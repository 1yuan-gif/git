# git

这是我的第一个 Git 仓库。

## 说明

- 本仓库用于练习 Git 与 GitHub 的协作流程
- 当前仓库为**私有**仓库

## 常用命令

```bash
# 查看状态
git status

# 添加改动
git add .
# 或添加单个文件
git add 文件名

# 提交
git commit -m "提交说明"

# 推送到 GitHub
git push

# 查看历史
git log --oneline
```

## 上手流程

1. 改文件
2. `git add .`
3. `git commit -m "说明"`
4. `git push`
